## Processing

- Download via Commons API / upload.wikimedia.org (prefer high resolution; thumbnails ≤3840px for very large files).
- Center-crop (or focus-crop for tall portraits) to 16:9, then resize to 1280×720 JPEG quality 85.
- Originals retained under `src/` for audit; outputs under `out/`.
